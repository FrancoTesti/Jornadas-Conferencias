# Diseño de Sistemas: Prácticas UML y Arquitectura MVC

Este repositorio contiene ejercicios de modelado de software orientados a objetos, enfocados en resolver reglas de negocio mediante patrones de diseño.

## Conceptos Técnicos Aplicados:
* Patrón de arquitectura MVC (Modelo-Vista-Controlador).
* Diagramas de Secuencia de Diseño (DSD) para análisis de casos de uso.
* Diagramas de Clases de Diseño (DCD).
* Gestión de colecciones, persistencia de datos y patrón DAO.

## Proyectos Analizados:
* **Gestión de Jornadas Universitarias:** Asignación de salones, control estricto de cupos y validación lógica de superposición de horarios.
